# Схема файлов результатов TSE (2026)

Фактическая схема по живым файлам второго тура (`ele2026/6258`) и итоговому файлу первого тура (`ele2026/6257`).
Все числа в TSE приходят **строками**; дробные с запятой (`"48,728274574"`). Поля с суффиксом `n` дают полную точность
(`pvapn`, `pstn`), без суффикса округлены до 2 знаков.

## `<abr>-c0001-e006258-u.json` (unificado)

```jsonc
{
  "ele": "6258", "t": "2",          // выборы, тур
  "f": "o",                         // ambiente: oficial
  "tpabr": "br", "cdabr": "br",     // тип/код абрангенсии (br, uf, mu)
  "dg": "25/10/2026", "hg": "20:52:51",  // дата/время генерации файла (Бразилиа)
  "dt": "25/10/2026", "ht": "20:52:44",  // дата/время тотализации (используем как sourceUpdatedAt)
  "tf": "n",                        // totalização finalizada: "s" в итоговом файле
  "and": "p",                       // andamento: "p" частичный, "f" финальный
  "md": "n",                        // matematicamente definido: "n" → "e" при 98,76% (см. verification-log)
  "carg": [{
    "cd": "1", "nmn": "Presidente",
    "agr": [{                       // коалиции / партии
      "par": [{ "n": "13", "sg": "PT",
        "cand": [{
          "n": "13", "nmu": "LULA", "sqcand": "280002542548",
          "vap": "50706005",         // голоса
          "pvap": "51,27", "pvapn": "51,271725426",  // доля от валидных, %
          "e": "n", "st": "",        // избран (s/n), статус ("Eleito", "2º turno", "Não eleito")
          "dvt": "Válido"
        }]
      }]
    }]
  }],
  "s": {                            // секции (участки, urnas)
    "ts": "499248",                 // всего
    "st": "399484", "pst": "80,02", "pstn": "80,017145787",  // тотализировано
    "snt": "99764"                  // не тотализировано
  },
  "e": {                            // электорат
    "te": "158745502",              // всего избирателей
    "est": "126070861",             // избирателей в подсчитанных секциях
    "c": "102134112",               // явка (comparecimento) в подсчитанных
    "a": "23936326"                 // неявка
  },
  "v": {                            // голоса
    "tv": "102134112",              // всего
    "vv": "98896623",               // валидные
    "vb": "1124066",                // пустые (brancos)
    "tvn": "2113423",               // недействительные (nulos), всего
    "van": "0"                      // аннулированные
  }
}
```

Используемые поля: `dt/ht`, `dg/hg`, `tf`, `and`, `md`, `s.ts/st/pstn`, `e.te/est/c`, `v.vv/vb/tvn`,
`cand[].n/vap/pvapn/e`. Кандидаты определяются по номеру: Лула `13`, Флавио `22`.

## `br-e006258-ab.json` (acompanhamento)

Ход подсчёта по всем абрангенсиям (`abr[]`, `tpabr: "uf"`, `cdabr: "ac"…"zz"`, плюс `"br"`): `s` (секции), `e` (электорат),
число муниципалитетов не начато/в процессе/завершено (`munnr`, `munpt`, `munf`). **Голосов кандидатов нет**, поэтому для
таблицы штатов берём 28 файлов `<uf>-…-u.json`.

## Муниципалитеты Сан-Паулу

`config/mun-e006258-cm.json`: `abr[].mu[]` = `{ cd (код TSE, 5 цифр), cdi (IBGE), nm, c ("s" = столица), z (зоны) }`.
Коды 39 муниципалитетов RMSP разрешены по IBGE-кодам и зашиты в `workers/api/src/tse.ts` (`GRANDE_SP`).
