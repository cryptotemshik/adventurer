# food-bot

Телеграм-бот с вариантами еды для Андрея. Ветка отдельная от проекта, кода проекта здесь нет.

- Две запланированные задачи Claude (16:00 и 20:30 по Москве) ищут рестораны с доставкой
  на Софийскую набережную, 34 и кладут пост в `outbox/<дата>-<breakfast|dinner>.json`.
- Workflow `.github/workflows/food-bot.yml` на push в эту ветку отправляет новый пост в канал:
  сообщение с вариантами и следом анонимный опрос (можно выбрать несколько).
  Если пост пришёл раньше `send_at`, workflow ждёт до этого времени.
- Канал задаётся в `config.json` (`chat_id`: `@username` или числовой id).
- Токен бота — секрет репозитория `TELEGRAM_BOT_TOKEN`.

Формат поста описан в начале `bot/send.py`. Проверка без отправки: `DRY_RUN=1 python3 bot/send.py outbox/<файл>.json`.

## Запросы «Хочу …»
Админ канала пишет в канал сообщение, начинающееся с «Хочу» (например, «Хочу том ям»). Workflow
`food-bot-requests` в основной ветке (`dapp`) раз в 5 минут забирает такие посты, запускает Claude Code
(секрет `CLAUDE_CODE_OAUTH_TOKEN`) с `bot/request_prompt.md` и отвечает реплаем: 3 варианта из
`restaurants.md`, от дешёвого к дорогому. Код — `bot/requests.py`.
